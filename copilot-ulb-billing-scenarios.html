關鍵概念

AI Credits
計費單位
1 credit = $0.01 USD
Pool（池）
所有 seat 的 included credits 合併為共享池，非個人 bucket。新增 license 立即增加；移除於下帳期縮減
ULB
User-Level Budget — 追蹤每人總消耗（pool + overage），到限即停。$0 = 完全無法使用
Org Budget
控制 org 層級的 additional usage（超額）花費上限
Enterprise Budget
控制整個 enterprise 超額花費上限，跨所有 org 的全局剎車
Stop usage 勾選
Budget 上的「Stop usage when budget limit is reached」— 勾選才是 hard stop，未勾選只發 alert。Budget = $0 + 勾選 = 不允許超額

  • 任一使用者可消耗大量 Pool，無個人上限
  • 一個 power user 使用 agent mode 跑整天，可能吃掉大部分 Pool
  • Pool 耗盡後，依 Org Budget 允許最多 $100 overage

管理要點

1

務必勾選「Stop usage when budget limit is reached」

設定 budget 時，必須勾選此選項才能 hard stop。

若未勾選，budget 只是 alert，不會阻止 usage，可能導致帳單超出預期。這是最常見的管理疏忽。
Setting up budgets Stopping usage
2

用 Budget 金額來控制是否允許超額

新版 GitHub Billing UI 沒有獨立的「Additional usage allowed / not allowed」開關，這個控制已經整合到 Budget 設定裡。實際決定行為的是「Budget 金額」加上「Stop usage when budget limit is reached」勾選框：

  • Budget = $0 + Stop usage 勾選：等同「Not allowed」— Pool 用完就全停
  • Budget > $0 + Stop usage 勾選：等同「Allowed up to budget」— Pool 用完後繼續使用，費用依 published rates 計算，到 budget 上限就 hard stop
  • Stop usage 未勾選：Pool 用完後無上限超額，budget 只發 email 警示，不建議
  • 沒設 Budget：依 plan 預設行為（Business/Enterprise 預設不允許超額；個人 Pro 帳號預設行為依 GitHub plan 條款）
Set up budgets Exceed included credits
3

啟用 Included Usage Alerts

可在 Budgets & Alerts 頁面啟用 included usage alerts：

  • Pool 到 90% 和 100% 時寄 email 通知
  • 這和 budget alerts 是不同的機制：一個追蹤 included usage 消耗比例，一個追蹤 dollar budget
  • 建議兩者都啟用
